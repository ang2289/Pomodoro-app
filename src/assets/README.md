# Assets 目錄

請將以下圖示檔案放入此目錄中：

## 底部導覽列圖示

1. **icon_flower.png** - 唸經頁面圖示
   - 建議尺寸：32x32px 或 64x64px
   - 格式：PNG（支援透明背景）

2. **icon_tomato.png** - 番茄鐘頁面圖示
   - 建議尺寸：32x32px 或 64x64px
   - 格式：PNG（支援透明背景）

3. **icon_todo.png** - 待辦頁面圖示
   - 建議尺寸：32x32px 或 64x64px
   - 格式：PNG（支援透明背景）

4. **icon_wish.png** - 集氣頁面圖示
   - 建議尺寸：32x32px 或 64x64px
   - 格式：PNG（支援透明背景）

## 使用方式

這些圖示會在 Footer.tsx 中被引用，路徑為：
- `/src/assets/icon_flower.png`
- `/src/assets/icon_tomato.png`
- `/src/assets/icon_todo.png`
- `/src/assets/icon_wish.png`

## 注意事項

- 確保圖示檔案名稱與上述完全一致
- 建議使用透明背景的 PNG 格式
- 圖示應該簡潔明瞭，適合小尺寸顯示
